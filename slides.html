AI Co-Creation

人機協作：如何調教出有溫度的 AI？

1. Prompt Engineering 與情緒邊界

導入非暴力溝通 (NVC) 心理學框架：先確認情緒 ➔ 給予共情 ➔ 換位思考 ➔ 給出微行動。嚴格限制「不講大道理」，賦予三位店長鮮活的說話口吻。

2. 結構化輸出 (JSON Mode)

要求 Gemini API 輸出結構化 JSON（letter 長信、quote 金句、action 微任務），讓前端能無縫分離並精準排版至拍立得卡片。

3. 客戶端渲染攻堅 (html2canvas)

與 AI 協同除錯，在不依賴後端伺服器的情況下，調校 Retina 2.5x 解析度與 DOM 盒模型，讓純前端直接產生媲美設計軟體的拍立得圖檔。

4. 雙模設計 (高可用離線備援)

為確保課堂與網路斷線時 Demo 零出錯，設計了免金鑰的智慧離線備援庫，讓任何人點開網址都能 100% 順暢體驗！
